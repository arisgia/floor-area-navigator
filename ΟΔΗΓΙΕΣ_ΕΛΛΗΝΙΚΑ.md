# Εγκατάσταση

**Home Assistant 2026.11+**: Settings → Marketplace → Add from link → https://github.com/arisgia/floor-area-navigator → Install.

**Home Assistant παλαιότερο / HACS**: HACS → ⋮ → Custom repositories → πρόσθεσε https://github.com/arisgia/floor-area-navigator με τύπο **Dashboard** → Install.

Μετά ανανέωσε τον browser. Δημιούργησε νέο Dashboard και πρόσθεσε Manual card:

```yaml
type: custom:floor-area-navigator
title: Το σπίτι μου
```

Στις Ρυθμίσεις → Areas, labels & zones ανάθεσε τα Areas στους ορόφους τους και τις συσκευές στο αντίστοιχο Area. Η κάρτα ανακαλύπτει αυτόματα Floors, Areas και Entities.

Η εγκατάσταση προσθέτει μια κάρτα, όχι αυτόματα dashboard. Δεν τροποποιεί το παλιό dashboard.
